LLM inference

One explicit bounded synthetic provider call, available without the game. No private dialogue is sent by this check. Connectivity is not full gameplay-AI acceptance; loading or saving Settings never requests inference.

Saved games

Fully stopped game only. Saves include the world and paired history, not configuration or the preset store. Load overwrites current world/history, creates no automatic pre-load backup and does not start the game. Delete is permanent.

Danger zone: permanent world reset

Bots includes player-owned vassals. Partial wipes may be blocked by mixed bot/player trades. World deletion can commit before history cleanup fails; a failure is not proof of rollback. Protect unique data before proceeding.

Service information

L2Kingdom pages are served by the independent frontend at the browser origin. WorldObserver hostname/port identify the management backend; publicOrigin identifies the frontend. WorldObserver.enabled controls only the private game observer API. Bind and advertised client addresses are different settings.
